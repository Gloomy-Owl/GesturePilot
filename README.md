# GesturePilot 🖐️🚀

**GesturePilot** — это автономная система управления презентациями (PowerPoint и др.) с помощью жестов рук в реальном времени. Проект использует методы компьютерного зрения и машинного обучения (Multi-Layer Perceptron) для распознавания статических жестов и их конвертации в системные нажатия клавиш.

## 🌟 Особенности проекта
- **Надежность:** Использование полносвязной нейросети (MLP) вместо математики свайпов исключает ложные срабатывания при активной жестикуляции спикера.
- **Умный буфер (Debounce):** Система фильтрует случайные взмахи и реагирует только на зафиксированные жесты (задержка в 4 кадра).
- **Интеграция с PowerPoint:** Поддержка запуска презентации, навигации по слайдам и управления встроенным зумом.

## ✋ Словарь жестов
Система обучена на 8 уникальных жестах:
1. 🖐️ **Ладонь:** `F5` (Запуск презентации)
2. ✊ **Кулак:** `Холостой ход / Безопасная смена жеста`
3. 👈 **Большой палец ВЛЕВО:** `Стрелка Вправо` (Следующий слайд)
4. 👉 **Большой палец ВПРАВО:** `Стрелка Влево` (Предыдущий слайд)
5. ✌️ **Два пальца "V":** `+` (Приблизить слайд / Зум)
6. ☝️ **Указательный ВВЕРХ:** `Стрелка Вверх` (Панорамирование)
7. 👇 **Указательный ВНИЗ:** `Стрелка Вниз` (Панорамирование)
8. 👆👈 **Буква L:** `-` (Отдалить слайд)

## 🎮 Установка для пользователей (Без программирования)
Если вы хотите просто управлять презентацией, вам не нужен Python!
1. Перейдите в раздел [Releases](https://github.com/Gloomy-Owl/GesturePilot/releases) (справа).
2. Скачайте последний `.zip` архив.
3. Распакуйте папку и запустите `3_run_presentation.exe`.
4. Откройте PowerPoint и управляйте показом с помощью веб-камеры!

## 🛠 Архитектура для разработчиков
Проект четко разделен на 3 этапа для удобства модификации:
* `1_data_collection.py` — Сбор координат суставов (Landmarks) через MediaPipe Hands и формирование `gestures_dataset.csv`. (Включает авто-вычет координат запястья для инвариантности к позиции руки).
* `2_train_model.py` — Обучение нейросети MLPClassifier (Scikit-learn) на собранных данных и экспорт весов в `gesture_model.pkl`.
* `3_run_presentation.py` — Распознает жесты с веб-камеры в реальном времени, сглаживает предсказания через буфер и вызывает команды через `PyAutoGUI`.
